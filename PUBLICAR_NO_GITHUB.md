# Como publicar no GitHub

O repositório **ainda não foi publicado automaticamente**. Crie no GitHub um repositório **público** com o nome `algoritmos-estrutura-dados-I`, sem inicializar README, licença ou .gitignore (já há arquivos locais).

No terminal aberto na pasta do projeto, execute:

```powershell
git init
git branch -M main
git add .
git commit -m "Organiza entregáveis e projeto integrador de AED I"
git remote add origin https://github.com/igorbrandaof/algoritmos-estrutura-dados-I.git
git push -u origin main
```

Substitua `igorbrandaof` pelo nome da sua conta. Autentique-se quando solicitado. No GitHub, configure a descrição: `Projeto acadêmico de Algoritmos e Estrutura de Dados I em Python — UNIALFA`, e tópicos `python`, `algoritmos`, `estruturas-de-dados`, `engenharia-de-software`, `projeto-academico`.

Antes de publicar, revise dados pessoais, autoria e documentos. **Licença:** não foi incluída uma licença porque você ainda não escolheu os termos de uso; repositório público não implica autorização irrestrita de reutilização. Se desejar, escolha uma licença explicitamente.
