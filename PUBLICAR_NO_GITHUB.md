# Publicação da versão com GUI

Destino existente: `igorbrandaof/algoritmos-estrutura-dados-I`.

1. Revisar o pacote e a lista de alterações.
2. Obter aprovação explícita antes de qualquer escrita no GitHub.
3. Conferir a versão remota para preservar alterações posteriores.
4. Criar uma branch com as mudanças aprovadas e abrir pull request para revisão.
5. Inspecionar os resultados do workflow; merge somente quando autorizado.

Nenhuma alteração de visibilidade é incluída. O repositório já estava público na inspeção; esta proposta não autoriza mudança de público/privado.
