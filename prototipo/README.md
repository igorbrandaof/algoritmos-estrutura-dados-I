# Protótipo para apresentação

1. Abra [index.html](index.html) no GitHub e clique no ícone **Download raw file** (seta para baixo).
2. Na pasta Downloads, abra o arquivo `index.html` com o Chrome ou Edge.
3. Para demonstrar o cadastro, use **Cadastro de clientes → Preencher exemplo fictício → Salvar ficha → Usar nome na triagem**. Em seguida, escolha o serviço e gere a senha.

O arquivo funciona offline e não exige Python. Use apenas dados fictícios; as fichas ficam na memória da aba.
